# Site - Clínica Dr. Pontim

## Como rodar localmente
1. Instale o Node.js (>=18).
2. No terminal:
```bash
npm install
npm run dev
```
Abra http://localhost:5173

## Build para produção
```bash
npm run build
npm run preview
```

## Estrutura
- `src/App.jsx` — código do site
- `public/logo-dr-pontim.png` — logo
- `public/equipe-dr-pontim.jpg` — foto da equipe
